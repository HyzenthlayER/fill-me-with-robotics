# fill-me-with-robotics

**An empty repository. An open experiment.**

This project starts empty. It welcomes any PR related to robotics software. There is no roadmap or predetermined direction. With minimal supervision, contributions determine what it becomes.

## Contribute

1. Fork this repository.
2. Make your contribution.
3. Open a PR and briefly explain the connection, what changed, and what you checked.

No prior issue or permission is required. There is no required programming language, framework, or architecture.

Read the [contribution rules](CONTRIBUTING.md). [AGENTS.md](AGENTS.md) provides guidance for agents and Codex reviewers.

## How the experiment works

- **Direction comes from PRs.** The project has no prescribed destination.
- **Review should be light.** Contributions within scope are eligible for merging when they respect the contribution rules. Personal preferences are not admission criteria.
- **Codex is the intended first reviewer.** The owner will enable automatic review for every PR. Repository instructions are ready; adding these files does not enable the service. Setup follows the [official OpenAI documentation](https://learn.chatgpt.com/docs/third-party/github).
- **Merging is a separate step.** The owner handles merges with minimal intervention. A bot review, a reaction, or an absence of findings is not an automatic merge or proof that something is safe to run. No automatic merge workflow is installed at the start.
- **The history is part of the experiment.** Use PRs for subsequent changes, including changes to the rules. Explain a rule change explicitly. The owner may intervene for concrete rule violations or repository abuse; preserve the original PR and reason when reverting a contribution.

Started **2026-10-23**, with only repository documentation and configuration. Git and PR history record what happens next.
